# 存量页面布局与交互验收

适用于已接入规范的 PC 页面。审计先确认组件、运行环境和现有业务行为，再按下表决定是否调整。列表、作业台、报表、时间轴和详情页可以使用不同布局。

| 结论 | 依据 | 处理 |
|---|---|---|
| 已确认的规范偏差 | 规则适用于该组件，源码能确认缺项，例如普通工具栏缺少明确尺寸 | 按页面范围最小修复，复扫并复核渲染 |
| 已复现的交互缺陷 | 能说明窗口尺寸、数据、操作步骤和实际结果 | 保留原业务行为，局部修复并用相同步骤回归 |
| 静态预警或建议 | 扫描提示标签可能截断、建议页签样式或空态操作 | 先检查实际效果和已有入口。未复现或无法实测时，分别记为未复现或待验证 |
| 业务布局与组件差异 | 已确认的固定列、报表对齐、手柄有无、列宽策略或特殊操作控件 | 核对原有行为。确需保留的规则例外按项目流程记录依据 |

## 浏览器复核

| 区域 | 操作 | 通过条件 |
|---|---|---|
| 查询和表单 | 在正常和窄窗口检查最长标签、带单位字段及日期框，再展开筛选和多选 | 标签完整，输入区有可用宽度，同列控件对齐，搜索操作保持靠右。R008 的静态宽度仅用于提示，按实际内容和列数分配空间 |
| 表格列宽与选择 | 用空表、长编号和长备注首进、翻页、切页返回、恢复已有列配置。横滚并验证排序、单选和多选 | 关键字段按业务要求可读。普通长文本仅在溢出时省略并可查看全文。固定列和选择列可操作，当前筛选和选择行为正确 |
| 分栏和手柄 | 对有分栏的页面分别测试空、少量、满页数据。拖动后再查询、切页签和缩放。对无分栏长页滚到最后一区 | 自动分配遵循页面原定策略。手动位置按组件约定保留。上下区能滚到末行，空态完整，手柄可拖。无分栏长页由页面容器滚动 |
| 弹窗、抽屉和二级选择 | 填草稿后试遮罩、Esc、取消、关闭叉。打开子选择或日期浮层，验证回填、取消、焦点返回、失败和成功提交 | 录入窗遵循显式退出约定。父窗草稿保留，子层可操作。滚动时可到达分页和底部按钮，失败可修正后再提交 |
| 页签和反馈 | 切换后返回。分别模拟未选主表、无记录、查询失败 | 页签内容与上下文一致。未选时给选择提示，失败时复用可恢复的入口。已有查询或刷新可恢复时保留该入口 |
| 特殊操作控件 | 检查时间轴、选择卡、浮层触发器在鼠标和键盘下的行为 | 改造前后保留点击热区、选中反馈、键盘焦点、弹层定位和既有双击等操作 |

记录页面、组件或规则、环境、窗口尺寸、数据与步骤、预期与实际结果。截图可说明几何表现，动态交互需要执行记录。静态检查通过只证明对应检查通过。

## 修改范围

优先在当前页面或组件修复。标签宽度、分栏初始高度、需全文展示的字段和业务颜色由消费项目决定。共享组件、样式或运行时有改动时，同测受影响的其他调用方和一个未改动的相邻页面。检查布局改动是否引起额外请求、选中状态重置或滚动位置异常。

分栏内部尺寸处理见[上下分屏 AG Grid 尺寸重布局](../../docs/split-grid-resize.md)。弹窗分页位置见[弹窗内分页](05-dialog-pagination.md)。
